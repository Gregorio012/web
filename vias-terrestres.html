Medición del terreno.

Es un proceso fundamental que implica determinar con precisión las dimensiones, características y ubicación de un área de terreno. Estas mediciones son necesarias para la planificación, diseño, construcción y mantenimiento de las vías terrestres como carreteras, caminos y autopistas. Incluye actividades específicas como:

Topografía:

Consiste en realizar levantamientos topográficos para obtener un mapa detallado del terreno. Se utilizan instrumentos como niveles, estaciones totales, GPS y drones para medir altitudes, pendientes, distancias y coordenadas.

Cálculo de Áreas y Volúmenes:

Se mide el terreno para calcular áreas y determinar los volúmenes de tierra necesarios para excavación o relleno. Esto es esencial para el diseño de cortes y terraplenes.

Medición de Coordenadas:

Se determinan las coordenadas geográficas o UTM para ubicar el terreno en un sistema de referencia. Estas mediciones ayudan a integrar los datos del terreno con planos y sistemas GIS.

Control de Niveles:

La medición del terreno permite establecer cotas o niveles, necesarios para garantizar la correcta pendiente de las vías y evitar problemas como acumulación de agua.

Estudios de Suelos:

Aunque más específicos, estas mediciones del terreno incluyen investigaciones para determinar la capacidad portante, el tipo de suelo y su estabilidad.


Construcción de subrasantes.

La construcción de subrasantes es una de las etapas iniciales en la construcción de vías terrestres, como carreteras y autopistas. La subrasante se refiere a la capa de terreno natural o mejorado que sirve como base para las capas superiores de la estructura del pavimento (subbase, base y carpeta asfáltica o de concreto).

Pasos en la construcción de subrasantes:


Preparación del terreno.

Corte y relleno.

Compactación.

Control de pendientes y nivelación.

Mejoramiento del suelo (si es necesario).

Drenaje.

Control de calidad.

Contrucción y nivelación de base hidráulica.

La construcción y nivelación de una base hidráulica consiste en preparar una capa de material granular estabilizado con agua, que sirve de soporte para las capas superiores del pavimento. Este proceso incluye compactar el terreno, distribuir uniformemente el material granular, ajustar la humedad para lograr la densidad óptima y nivelar la superficie según las especificaciones del diseño. En algunos casos, se estabiliza con aditivos como cemento o cal para mejorar la resistencia. Finalmente, se realizan controles de calidad para garantizar la estabilidad, uniformidad y resistencia de la base.



Construcción de pavimentos hidráulicos.

La construcción de pavimentos hidráulicos se refiere al proceso de crear superficies de rodamiento hechas con concreto hidráulico, diseñado para soportar cargas pesadas y ofrecer una larga vida útil. Este tipo de pavimento es ideal para carreteras, autopistas, aeropuertos y zonas industriales debido a su alta resistencia y bajo mantenimiento.


Preparación del terreno:

Se estabiliza la subrasante y las capas base para garantizar una superficie firme y uniforme.

Colocación del concreto hidráulico:

Se mezcla y vierte el concreto directamente sobre la base preparada, asegurando una distribución uniforme. Puede utilizarse concreto premezclado o preparado en el sitio.

Compactación y nivelación:

Se utiliza equipo especializado para compactar y nivelar el concreto, eliminando huecos y logrando la pendiente requerida.

Formación de juntas:

Se crean juntas de dilatación y contracción para evitar grietas debido a cambios de temperatura y carga.

Curado:

El concreto se cura para evitar deshidratación rápida, generalmente rociando agua o aplicando compuestos selladores.



Construcción de pavimentos con carpeta asfáltica.

La construcción de pavimentos con carpeta asfáltica implica la creación de una capa superficial de rodamiento hecha de mezcla asfáltica, colocada sobre una base previamente preparada. Este pavimento se caracteriza por su flexibilidad, capacidad para soportar cargas dinámicas y su adaptabilidad a diversas condiciones climáticas. La carpeta asfáltica se compone de agregados minerales y asfalto como aglutinante, mezclados y colocados en caliente. El proceso incluye la preparación del terreno, la colocación y compactación de la mezcla, y la aplicación de un acabado que garantiza la uniformidad y durabilidad del pavimento. Es ideal para carreteras, calles y pistas de aeropuertos.



Riegos de liga.

El riego de liga es una técnica utilizada en la construcción de pavimentos para unir firmemente dos capas, generalmente entre la base (o subbase) y la carpeta asfáltica. Consiste en la aplicación uniforme de un material bituminoso, como emulsión asfáltica o asfalto diluido, que actúa como adhesivo para mejorar la cohesión entre las capas y evitar el deslizamiento o separación bajo las cargas del tráfico.

Características del riego de liga:

Material:

Se utiliza un ligante bituminoso, como emulsión asfáltica CSS-1h, asfalto diluido o asfalto caliente.

Propósito:

Garantiza una unión adecuada entre las capas, distribuyendo mejor las cargas y aumentando la vida útil del pavimento.

Aplicación:

Se realiza de forma uniforme con equipo especializado, como distribuidores de riego, para asegurar una cobertura completa sin excesos ni faltantes.

Procedimientos:

Preparación de la superficie:

La base debe estar limpia, seca y nivelada para asegurar la correcta adherencia del ligante.

Riego:

Se aplica el material bituminoso en la cantidad especificada, dependiendo del diseño del pavimento.

Tiempo de curado:

Se deja un tiempo adecuado para que el riego forme una película adhesiva antes de colocar la capa superior.


Recuperación de carpetas.

La recuperación de carpetas asfálticas es una técnica utilizada en la rehabilitación de pavimentos que han sufrido deterioros significativos, como fisuras, baches, deformaciones o pérdida de capacidad estructural. Este proceso busca restaurar las propiedades funcionales y estructurales del pavimento, aprovechando en lo posible los materiales existentes para reducir costos y minimizar el impacto ambiental.

Aplicaciónes:

Se utiliza principalmente en carreteras, calles y autopistas con tráfico moderado a alto que requieren una rehabilitación rápida y eficiente sin interrumpir significativamente el flujo vehicular. La recuperación de carpetas es una solución moderna y eficiente para garantizar la durabilidad de las vías con un enfoque sostenible y económico.
